The rules for building workflows that don't break:
  • Human checkpoints on anything customer-facing. AI drafts the email. A person clicks send.
  • One workflow at a time. Get it stable for 2 weeks before building the next one.
  • Log everything. Every automation should write to a log sheet so you can audit what happened.
  • Build from your existing SOPs. If you don't have written processes, write them first. You can't automate what you can't explain.

Key Takeaway: Start with one workflow. Get it stable. Then add the next. Most businesses hit 20+ hours saved per week within 3 months.

Watch Out

Common Mistakes

Mistake 1: Letting everyone pick their own AI tool+

This is the big one. Five people using five different AI tools means five different contexts, no shared learning, and zero compounding value. Centralise on one platform.

Mistake 2: Automating before documenting+

If your process isn't written down step by step, don't automate it. You'll build a fast version of a broken process. Write the SOP first, then automate.

Mistake 3: Going straight to enterprise tools+

You don't need a $50K Salesforce implementation. Claude Team + n8n + Xero handles 90% of what a $5M-$100M business needs. Start simple, add complexity when the simple stuff is running.

Mistake 4: No human checkpoints+

AI makes mistakes. Not often, but when it does, you want a human catching it before it reaches a client. Every workflow that touches customers should have an approval step.

Mistake 5: Building it yourself with no plan+

Watching YouTube tutorials and stitching together random automations creates technical debt. Start with a proper architecture. Know which tools connect where before you build anything.

Key Takeaway: The biggest mistake is treating AI like individual productivity tools instead of shared business infrastructure.
