Step 1: Understand What You're Building

Two open source projects. Both free. They do completely different jobs.

📋 Template
Kimi K2.5 — the brain

A 1 trillion parameter LLM from Moonshot AI. Open weights, MIT licence. It processes text, images, and video with a 256K token context window — that's roughly 500 pages of text in a single conversation.

It does roughly 90% of what Claude and GPT do, at a fraction of the cost. For agent tasks, it's specifically built for it — it can run up to 100 sub-agents in parallel with up to 1,500 tool calls per session.

Security

Keep It Secure (Don't Skip This)

Your agent has access to your email, messages, and potentially business data. Lock it down.

3 rules:

1. Restrict what it can do. In ~/.openclaw/openclaw.json, set permissions carefully. Start with read-only access to email and calendar. Only grant write/send access after you trust it.

2. Use human checkpoints for anything external. The heartbeat templates above include "send me for approval" steps intentionally. Never let the agent send emails to clients or post publicly without your sign-off — at least for the first month.

3. Keep OpenClaw updated. Run npm update -g openclaw@latest regularly. Earlier versions had a known vulnerability (CVE-2026-25253) in the skill repository that was patched in version 2026.1.29. Make sure you're on a recent version.

🔑

Key Takeaway: Start read-only. Add write access gradually. Always keep a human in the loop for external communications. Update regularly.

Watch Out

Common Mistakes

Mistake 1: Self-hosting the LLM before testing the API+

The API costs cents to test. Self-hosting needs GPU hardware, Docker, and hours of setup. Use the API first. Self-host once you know the stack works for your use case.

Mistake 2: Automating customer-facing tasks first+

One wrong email to a client costs more than the time you saved. Start with internal tasks — morning briefings, report summaries, data lookups. Expand outward once you trust it.

Mistake 3: Writing vague heartbeat instructions+

"Monitor my business" means nothing to an agent. "Check Gmail for emails from @supplier.com, summarise any with the word 'invoice' in the subject, send me the summary on WhatsApp" — that works.

Mistake 4: Giving it full permissions on day one+

Read-only first. Let it summarise emails before you let it reply. Let it draft invoices before you let it send them. Build trust gradually.

Mistake 5: Not reading the logs for the first week+

OpenClaw logs every action at ~/.openclaw/logs/. Read them daily for the first week. You'll catch mistakes early and learn what the agent handles well versus where it struggles.
