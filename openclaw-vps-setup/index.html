01

What is OpenClaw?

OpenClaw (formerly Moltbot / Clawdbot) is an open-source, self-hosted AI assistant gateway. It connects the messaging apps you already use — WhatsApp, Telegram, Discord, Slack, and more — directly to AI models like Claude or GPT-4.

Instead of paying for yet another SaaS AI subscription, you run it on your own server, keep your data private, and pay only for the API calls you actually make.

ℹ️
Why a VPS instead of your laptop or a Mac Mini? A VPS is a cheap cloud server that runs 24/7. When you close your laptop, your assistant goes offline. A VPS keeps it running constantly, is far cheaper than a Mac Mini (~$6–10/month vs $500+ upfront), and is more secure since it's isolated from your personal machine.
⚠️
Claude subscription note: As of January 2026, Anthropic enforces its Terms of Service — Claude Pro/Max subscription OAuth tokens no longer work with third-party tools like OpenClaw. You'll need an Anthropic API key (pay-per-use) instead, or use OpenAI / Gemini / Ollama.

03

Set Up Your Server

Once you've created your VPS (choose Ubuntu 22.04 or 24.04 when prompted), you'll receive an IP address, username (usually root or ubuntu), and either a password or SSH key.

Connect via SSH

Your Terminal
# Replace YOUR_SERVER_IP with the IP from your provider
ssh root@YOUR_SERVER_IP

Update the System First

SSH — Run on Server
# Always update before installing anything
apt update && apt upgrade -y

Create a Dedicated User (Recommended)

Running OpenClaw as root is a security risk. Create a dedicated user instead:

SSH — Run as Root
# Create a new user named "openclaw"
adduser openclaw
usermod -aG sudo openclaw
# Switch to the new user
su - openclaw

Set Up Firewall (UFW)

SSH — Firewall Rules
# Block all incoming traffic, allow only SSH
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw limit 22/tcp   # Rate-limit to slow brute-force attacks
sudo ufw enable
sudo ufw status

Enable Automatic Security Updates

SSH
sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure -plow unattended-upgrades
04

Install OpenClaw

The official installer script handles everything — Node.js detection, installation, and onboarding — in one command.

ℹ️
The installer requires Node.js 24 (recommended) or Node.js 22.16+ LTS. If you don't have it, the script installs it automatically. OpenClaw requires Node.js — not Docker (though Docker is an alternative install method).

Run the Installer

SSH — The One Command
curl -fsSL https://openclaw.ai/install.sh | bash

The script will launch an interactive onboarding wizard. It will ask you several questions — here's what to choose:

QuestionWhat to ChooseWhy
Where is the gateway running?Local (this machine)Gateway runs on your VPS — correct
AI ProviderAnthropic / OpenAI / GeminiSee Step 5 for details
Messaging channelYour preferenceTelegram is easiest to start with
Install as daemon?YesKeeps OpenClaw running 24/7 on restart

Verify the Installation

SSH — Check Everything Works
openclaw doctor    # Check for config issues
openclaw status    # See if gateway is running
openclaw dashboard # Open the browser UI (via SSH tunnel)
⚠️
Command not found? Your PATH might not include npm global binaries. Fix it by running:
export PATH="$(npm prefix -g)/bin:$PATH"
Then add that line to your ~/.bashrc to make it permanent.

Optional: Enable Startup Performance Cache

On small or ARM VMs, CLI commands can feel slow. Enable Node's compile cache to speed things up:

SSH — Performance Tuning
grep -q 'NODE_COMPILE_CACHE' ~/.bashrc || cat >> ~/.bashrc <<'EOF'
export NODE_COMPILE_CACHE=/var/tmp/openclaw-compile-cache
mkdir -p /var/tmp/openclaw-compile-cache
export OPENCLAW_NO_RESPAWN=1
EOF
source ~/.bashrc

Setting Up Telegram (Recommended for Beginners)

Telegram requires creating a "bot" — which is just a special Telegram account your OpenClaw talks through.

  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the prompts to name your bot
  3. BotFather will give you a bot token — copy it
  4. In OpenClaw, run openclaw channels add telegram
  5. Paste the token when prompted
  6. Send a message to your bot in Telegram — it should respond!
SSH — List Connected Channels
openclaw channels list   # See all connected channels
ℹ️
Telegram bot not responding? Verify your bot token is correct with openclaw channels list. Also check that your VPS can reach api.telegram.org — some providers block outbound traffic by default.

Setting Up WhatsApp

WhatsApp requires scanning a QR code to link your account — similar to WhatsApp Web.

  1. Run openclaw channels add whatsapp
  2. A QR code will appear in your terminal
  3. Open WhatsApp on your phone → Settings → Linked Devices → Link a Device
  4. Scan the QR code — you're connected
⚠️
If you see WhatsApp login failed: status=515 Unknown Stream Errored, go to Settings → Config and press Update, then return to Channels.

Secure Your Instance

Security is critical. OpenClaw can read your files, execute code, browse the web, and interact with services on your behalf. If it's exposed to the internet without protection, that's a serious risk.

Most Important: Bind Gateway to Localhost Only

This is the single most important security step. Your gateway should never be accessible directly from the internet.

SSH — Verify Gateway is on Localhost
openclaw configure
# When asked "where is the gateway?", choose "Local (this machine)"
# You want the gateway bound to 127.0.0.1:18789
# NOT 0.0.0.0:18789

Access the Control UI Securely via SSH Tunnel

Since the gateway is on localhost, access the web UI by forwarding the port to your own computer:

Your Local Machine (not the server)
# Run this on your laptop/desktop, not on the server
ssh -L 18789:localhost:18789 user@YOUR_SERVER_IP
# Then open this in your browser:
# http://localhost:18789

Optional but Recommended: Tailscale (Zero Public Ports)

Tailscale is a free VPN tool that makes your VPS invisible to the internet while still letting you access it. Zero public ports = near-zero attack surface.

SSH — Install Tailscale
# Install Tailscale on the VPS
curl -fsSL https://tailscale.com/install.sh | sh
# Start Tailscale with SSH enabled
sudo tailscale up --ssh
# Follow the auth link, then your VPS is on your private network

Set a Gateway Auth Token

SSH
# Add authentication so only you can access the gateway
openclaw configure
# Set gateway.auth.token to a strong random string

Disable Bonjour/mDNS

SSH
echo 'export OPENCLAW_DISABLE_BONJOUR=1' >> ~/.bashrc
source ~/.bashrc

Security Principles to Follow

  • Only give your agent the permissions it truly needs (least privilege)
  • Don't provide API keys it doesn't need access to
  • Use short-lived API keys and rotate them regularly
  • Be careful with web browsing — prompt injection via untrusted sites is a real risk
  • Only install skills from sources you truly trust
  • Keep the agent on a dedicated VPS, separate from your personal machine
  • Enable automatic security updates (done in Step 3)
08

Keep It Running

A few final steps to make sure OpenClaw stays healthy long-term.

Run as a System Service (Daemon)

If you set up OpenClaw as a daemon during onboarding, it will automatically restart if it crashes or the server reboots. Verify it's configured correctly:

SSH — Systemd Service Config
# Edit the systemd service for better reliability
sudo systemctl edit openclaw
# Add these lines in the editor:
[Service]
Environment=OPENCLAW_NO_RESPAWN=1
Environment=NODE_COMPILE_CACHE=/var/tmp/openclaw-compile-cache
Restart=always
RestartSec=2
TimeoutStartSec=90

Check Service Status

SSH — Service Management
sudo systemctl status openclaw    # Check if running
sudo systemctl restart openclaw   # Restart if needed
sudo journalctl -u openclaw -f    # View live logs

Update OpenClaw

SSH — Updating
npm install -g openclaw@latest
sudo systemctl restart openclaw

Back Up Your Data

Your config and conversation history lives on the VPS. Back it up:

SSH — What to Back Up
# Config file — your API keys, settings, channels
~/.openclaw/config.json
# Conversation history and memory
~/.openclaw/data/
# Example: copy to your local machine
scp -r user@YOUR_SERVER_IP:~/.openclaw/data ./openclaw-backup
✅
You're done! Your OpenClaw instance is now running 24/7 on a cheap VPS, accessible through your messaging apps, secured against the internet, and automatically restarting on any crash or reboot. Total cost: about $6–10/month in VPS fees, plus whatever API calls you make.
